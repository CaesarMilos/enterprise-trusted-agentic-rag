# V0.3.0 全面改造清单 / Comprehensive Change Log

## RC2 可靠性修复 / RC2 reliability repairs

- 在旧索引返回 Chunk ID 后再校验 `READY + active_version + active Source`，`PENDING_DELETE` 立即撤销在线证据。
- Worker 通过后台心跳续租；`lease_owner + attempt_count + expires_at` 构成 fencing token，Chunk、质量指标、终态和索引激活全部受保护。
- 索引激活先锁定租户发布行，再比较预期活动版本；过期计划保留 `STALE_INDEX_BUILD_PLAN` 错误语义。
- LLM 预算在真实请求前计数，坏 JSON 和 HTTP 异常均不能绕过上限；Embedding/LLM 失败回退到确定性本地算法。
- 新增 ASGI 完整请求体限制和 Nginx 前置上限，同时保留端点单文件限制。
- Docker 镜像安装 PyMuPDF、Tesseract 中英文语言包与 CJK 字体，增加可选真实 OCR 集成验收。

## 1. 文档接入与 PDF 完整性 / Ingestion and PDF completeness

- `ingestion/loaders/pdf_loader.py`：逐页检测文本层；原生文本页保留，缺页由 OCR 补齐；任何缺页未补齐则整份候选版本进入 `NEEDS_OCR`/`NEEDS_REVIEW`。
- `ingestion/pdf_reflow.py`：删除重复页眉页脚，修复视觉断行、孤立编号和标点，并保留物理页码。
- `infrastructure/ocr/tesseract_provider.py`：本地 PyMuPDF + Tesseract 逐页 OCR，输出页码、置信度和提供方版本。
- `api/routers/documents.py`：上传过程中按 1 MiB 分块累计大小，超过限制立即终止并删除临时文件。

## 2. 结构解析与自适应切块 / Structure parsing and adaptive chunking

- `ingestion/structure_parser.py`：标题进入可检索单元；识别章节、条款、分项和步骤；记录原文字符偏移。
- `ingestion/boundary_analyzer.py`：按硬结构、最大 Token、向量相似度、模糊区 LLM JSON 复核、长度压力回退的顺序判定边界。
- `ingestion/semantic_chunker.py`：生成叶子块、Token 有界父块、稳定 ID、邻接链、父子 ID、边界方法和置信度。
- `ingestion/chunk_strategies.py`：为 `general_prose`、`manual`、`technical_doc` 提供独立 V2 策略；说明书额外保护警告、步骤、故障和参数结构。
- LLM 只复核局部模糊切点，单文档最多调用 `llm_boundary_max_calls` 次；失败时回退确定性算法，不允许改写正文。

## 3. 版本冻结和质量门 / Frozen versions and quality gate

- `DocumentVersion` 冻结内容画像、策略 ID/版本、切块参数、Embedding 指纹和边界模型指纹。
- Worker 执行前核对冻结快照；配置或模型漂移时明确失败，不静默切换算法。
- `quality_validator.py` 统计叶子/父块数量、微块率、平均 Token、PDF Reflow 和画像结构信号；严重碎片化阻止发布。
- 质量指标和警告持久化到版本快照，并由文档详情 API 展示。

## 4. 中文检索与精确锚点 / Chinese retrieval and exact anchors

- `retrieval/identifier_normalizer.py`：把“第一百四十三条”等编号转换为 `clause:143`，同时支持章节、步骤、错误码和型号。
- `indexing/bm25_index.py`：中文二元词组、短语和规范锚点共享同一分词逻辑。
- `query_normalizer.py` 与 `query_rewriter.py`：查询改写后重新附加强锚点，避免模型漏掉条款号。
- `source_router.py`：弱分、并列过多或领先不足时搜索全部授权 Source，不在正式召回前猜错资料源。
- `vector_index.py`：ACL 过滤不足时逐步扩大向量候选窗口，直到补足结果或扫描完成。

## 5. 证据、父子去重与引用 / Evidence, hierarchy, and citations

- `dynamic_top_k.py`：只有存在替代文档时才启用单文档数量上限；同一父子家族只保留一条证据。
- `evidence_grader.py`：精确条款/步骤/错误码必须真实出现在证据中。
- `citation_verifier.py`：聚合每个引用支撑的回答词项，并围绕最佳匹配位置返回局部摘录。
- 索引使用包含标题与编号的 `retrieval_text`，引用仍展示可核对的正文 `text`。

## 6. 并发、重处理与索引发布 / Concurrency and publication

- SQLite 任务领取改为“候选 ID + 条件 UPDATE”原子竞争，不依赖无效的行级 `SKIP LOCKED`。
- 索引构建计划记录预期活动版本；激活时执行乐观并发校验，过期计划不能覆盖新索引。
- 重处理候选版本失败时，逻辑文档保持 `READY` 并继续指向旧活动版本。
- 重试选择最新失败候选任务；有旧活动版本时不会把逻辑文档改回 `PENDING`。
- Manifest 汇总混合索引内真实的 Chunk 策略版本。

## 7. 安全、认证与可观测性 / Security, authentication, and observability

- 新增受共享密钥保护的可信反向代理身份适配器；Demo 身份仍被生产配置拒绝。
- Agent 记录意图、检索、证据评估、改写、生成和引用校验的脱敏步骤。
- Trace 数据库摘要保存终态与聚合指标；授权后可读取对应 JSONL 步骤。
- 分享包排除 `.env`、数据库、上传文件、索引、Trace、报告和编辑器缓存。

## 8. 配置、界面和版本 / Configuration, UI, and release

- 候选包版本升级至 `0.3.0rc2`；通过完整发布门禁后再晋升为 `0.3.0`。默认中文 Embedding 为 `BAAI/bge-small-zh-v1.5`，重排模型为 `BAAI/bge-reranker-base`。
- 新增 OCR、语义模糊区、LLM 边界调用上限、父块和可信代理配置。
- Streamlit 上传说明与后端统一为 50 MiB，并使用 `ENTERPRISE_RAG_API_URL`。
- 数据库启动时幂等增加 `document_versions.ingestion_snapshot`；旧活动版本可继续服务，重处理后使用新策略。

## 9. 关键测试 / Key tests

- 民法典式断行恢复与“第一百四十三条”精确锚点；
- Markdown 标题硬边界、父子 Chunk 与单文档 Top-K；
- LLM 模糊边界单文档调用上限；
- 混合 PDF 原生页 + OCR 缺页合并，以及无 OCR 时整份拒绝；
- 冻结参数漂移拒绝、SQLite 防重复领取、过期索引激活拒绝；
- 中文 Source 路由安全回退、精确证据评级和局部引用摘录；
- 真实 SQLite + FastAPI + Worker + FAISS/BM25 + Chat 的离线模型边界端到端闭环。
